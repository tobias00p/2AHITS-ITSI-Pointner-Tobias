- Pipes
   ... verbinden zwei Befehle miteinander. Das Ergebnis vom ersten Befehl wird direkt an den nächsten Befehl weitergegeben. So können mehrere Befehle zusammen arbeiten.

- head
   ...zeigt die ersten Zeilen einer Datei an. Standardmäßig werden die ersten zehn Zeilen ausgegeben. So kann man schnell den Anfang einer Datei anschauen.

- grep
   ...sucht nach einem bestimmten Wort oder Muster in einem Text oder in einer Datei. Es zeigt alle Zeilen an, in denen das gesuchte Wort vorkommt.

- tr
   ...wird benutzt um Zeichen in einem Text zu ersetzen, zu verändern oder zu löschen. Der Befehl arbeitet meistens mit Text der über eine Pipe kommt.

- shuf
   ...mischt die Zeilen einer Datei oder Liste in eine zufällige Reihenfolge. Das wird oft benutzt um zufällige Auswahl zu machen.

- seq
   ...erzeugt eine Folge von Zahlen. Man kann zum Beispiel Zahlen von eins bis zehn automatisch ausgeben lassen.

- date
   ...zeigt das aktuelle Datum und die aktuelle Uhrzeit vom System an. Der Befehl kann auch verschiedene Datumsformate anzeigen.
